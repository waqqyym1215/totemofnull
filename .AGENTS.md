# AGENTS

Instructions for AI agents working in this repository. Read this first.

## What this is

A **Paper plugin** for **Minecraft 26.2** that adds the **Totem of Null** — a single totem that
summons **50 fake-player minions** to attack anyone not wearing full netherite armor with the
**Flow** trim. Full design rationale lives in [`README.md`](README.md).

## Build & test

```bash
./gradlew build          # compile + jar -> build/libs/totemofnull-paper-<version>.jar
./gradlew build -x test  # skip tests
./gradlew clean          # wipe build outputs
```

Requires **JDK 25** and internet access on first run (downloads the Paper dev bundle).

There is currently **no test suite**. Verification is: compile green, then load the jar on a
Paper 26.2 server and exercise the keybind.

## Architecture

```
src/main/java/com/waqqyy/totemofnull/
├── TotemOfNullPlugin.java   # main class: config, recipe, item registry, listeners
├── TotemItem.java           # the custom totem item + keybind activation
├── BotManager.java          # NMS fake-player spawn/tick/despawn (the risky part)
├── NullBot.java             # per-bot logic: targeting, golden apples, shield
├── ArmorKit.java            # netherite + Flow trim + Protection IV/Mending/Unbreaking III/Curse of Vanishing
└── util/                    # name generation, trim checks, etc.
src/main/resources/
├── plugin.yml
├── config.yml
└── lang/en_us.json
```

## Conventions

- **Java 25**, `options.release = 25`.
- **Package:** `com.waqqyy.totemofnull`.
- **Config-driven:** anything a server owner might want to tune goes in `config.yml` with a
  default, not hardcoded.
- **No secrets** in the repo. `local.properties` is gitignored.
- **Commit messages:** short imperative subject, no prefix noise. Reference the design decision
  in the body when it isn't obvious from the diff.

## Critical constraints

- **NMS is required.** Paper 26.2 has no fake-player API. `BotManager` reaches into
  `net.minecraft.server.*` — expect it to be the first thing to break on a version bump.
- **Compiled against Paper `26.2.build.135-stable`.** Do not assume the mappings survive a
  server update. If the server version changes, re-run the build and fix what breaks in
  `BotManager`/`NullBot` first.
- **Build via `paperweight-userdev`** (`io.papermc.paperweight.userdev` v2.0.0-beta.24). Do not
  swap it for a plain `paper-api` dependency — that would drop NMS access and the fake players
  would stop compiling.
- **Bots are simulated, not real clients.** They have no connection; the plugin drives them.
  Anything that needs a real client packet (e.g. genuine player-list ordering quirks) will need
  manual packet handling.

## Working in this repo

- Read `README.md` before changing behavior — it documents *why* things are the way they are.
- Keep commits small and focused; the build is the only test we have.
- After any NMS change, run `./gradlew build` and confirm the jar is produced before committing.
